# EduShield AI Lite

Use **CSV only for training**, and use **manual student entry in the app** for prediction/demo.

# Best Tech Stack

| Part          | Tool            |
| ------------- | --------------- |
| App/UI        | Streamlit       |
| ML            | Scikit-learn    |
| Training      | Google Colab    |
| Data Handling | Pandas          |
| Charts        | Plotly          |
| Model Saving  | Joblib          |
| Database      | SQLite          |
| Reports       | ReportLab       |
| Code Editor   | VS Code         |
| Help Tool     | GitHub Copilot  |
| Deployment    | Streamlit Cloud |

Avoid deep learning, TensorFlow, PyTorch, CatBoost. They are unnecessary.

# Step 4: Train Model in Google Colab

Use this prompt in GitHub Copilot inside Colab:

```text
Create a complete machine learning training notebook for student academic risk prediction using a CSV dataset.

Requirements:
- Load CSV with pandas
- Clean missing values
- Encode categorical columns
- Scale numerical columns
- Create target labels: Low Risk, Medium Risk, High Risk
- Train Logistic Regression and Random Forest models
- Compare accuracy, precision, recall, F1-score
- Save the best model using joblib as student_risk_model.pkl
- Save label encoders and scaler if needed
```

# Step 7: Add Rule-Based Risk Score

This makes your project more explainable.

Example logic:

```text
Attendance < 60% = +30 risk
Quiz average < 50 = +20 risk
Assignment average < 50 = +15 risk
Study hours < 2 = +15 risk
Previous GPA < 2.5 = +20 risk
```

Then show:

```text
ML Prediction: High Risk
Rule-Based Score: 82%
Final Decision: High Risk
```

This looks very professional.
