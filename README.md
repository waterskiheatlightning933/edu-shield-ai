## 📝 Usage Guide

### Manual Student Entry 👤
Click the "New Student" button on the left sidebar. Type the student name, grade level, and recent performance metrics into the form. Press "Submit" to save the record to your local database.

### Risk Assessment 📊
The software automatically calculates a score from 0 to 100 for each entry. A low score suggests the student tracks well. A high score flags the student for review. You can click on any individual record to see the reasoning behind the score.

### Analytics Dashboard 📈
Navigate to the "Dashboard" tab to see your classroom overview. The graphs show risk trends over time. Use these charts to prepare for staff meetings. You can filter data by grade level or specific time periods.

### Generating Reports 📄
If you need a physical copy for a parent meeting, locate the student record. Click the "Generate PDF" button. The system creates a clean, professional document. You can save this file to your computer or print it directly.

2.  Toggle the filters at the top of the dashboard to ensure you display current records.
